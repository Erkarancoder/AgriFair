# AgriFair 🌾

AgriFair is a comprehensive farm-to-market Agri-Tech marketplace connecting farmers directly with wholesalers, retailers, consumers, and buyers with transparent mandi pricing, deal negotiations, order tracking, and escrow payments.

## 🚀 Project Overview

- **Frontend (`/client`)**: React 19, Vite, Tailwind CSS v4, React Router v7, Lucide Icons, Recharts
- **Backend (`/server`)**: Node.js, Express v5, MongoDB/Mongoose, JWT Auth, Zod Validation

## 👥 Supported Roles
- **Farmer**: List crops, check mandi rates, receive offers, manage orders
- **Wholesaler**: Bulk buying, offer bidding, logistics tracking
- **Retailer**: Medium-scale purchasing, mandi price discovery
- **Consumer**: Direct farm-fresh produce shopping
- **Buyer**: General buyer portal
- **Admin**: System oversight, dispute handling, user verification

## 📦 Getting Started

### Client
```bash
cd client
npm install
npm run dev
```

### Server
```bash
cd server
npm install
npm run dev
```
